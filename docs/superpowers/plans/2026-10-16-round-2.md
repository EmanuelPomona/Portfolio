# Round 2 (clouds, scroll depth, longer loader, one-line Contact) Implementation Plan

> **For agentic workers:** this project executes by separate Claude Code sessions in their own
> worktrees (AGENT_PROTOCOL §15, §23), not subagents. Each task file in `docs/tasks/` is the
> self-contained unit; steps use checkbox syntax.

**Goal:** Ship the owner's four round-2 requests without losing v1's correctness, contrast, or speed.

**Architecture:** Frontend owns three tasks in its own files (sections, components, hooks, global
CSS). The stickman slice owns the loader timing. No contract shape changes; API.md §2.2 changes one
number (minimum 2.2s). No new dependency (ADR-002).

**Tech Stack:** Vite + React + TypeScript, plain CSS, Vitest + Testing Library (unchanged).

**Spec:** ADR-011 in `docs/DECISIONS.md`; `docs/DESIGN_BRIEF.md` "Motion vocabulary" (two new rows);
`docs/ACCEPTANCE.md` M-01 to M-05, K-01, L-07.

## Global Constraints

- No new dependency, no animation library (ADR-002).
- Motion is transform and opacity only; nothing animates layout properties or `filter` on large layers per frame.
- Every new motion is off, or instant, under `prefers-reduced-motion: reduce` (X-05), with all content present and visible.
- Clouds are photographic, cut from `backgrounds/alpine-valley` or `backgrounds/evergreen-forest` via `getMedia`; no drawn shapes, no CSS radial blobs, no new image downloads.
- Budgets: initial JS ≤ 110 KB gzip, CSS ≤ 25 KB gzip (F-02); CLS ≤ 0.05 (F-03); no horizontal overflow (R-01).
- X-02 contrast holds over every new layer, measured, not assumed.
- Contract files stay untouched by workers: `index.html`, `types.ts`, `media.ts`, `stickman/index.ts`, `stickman/types.ts`, `stickman/contract.test.tsx`, `flags.ts`, `vite.config.ts`.
- No em dash in interface copy (D-05).

## Review Focus

1. A visitor who jumps with a nav click or a `#about` link skips plates: those plates must end up revealed, never stuck hidden above the viewport. (TASK-108: `reveals an element that is already above the viewport`.)
2. A keyboard user tabs to a project link before its arrival ran: the focused element must be fully visible at once. (TASK-108: `focus within an unrevealed arrival reveals it immediately`.)
3. Reduced motion switched on mid-scroll: no element left offset or half transparent. (TASK-108: `clears depth offsets when reduced motion turns on`; TASK-107: `renders static layers under reduced motion`.)
4. Clouds behind captions on a phone (390) lowering caption contrast below 4.5:1. (TASK-107: X-02 re-measured at 390, 768, 1440 with the clouds at both ends of their drift.)
5. The longer loader making skip feel broken: a click at 300ms must still exit at once, the minimum never overrides a skip. (TASK-206: `a skip before the minimum still exits immediately`.)
